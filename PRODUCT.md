# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers building text-first multiplayer strategy games use StillWorld and
its examples to understand and apply the framework's integration boundary.

## Product Purpose

StillWorld provides a foundation for persistent worlds with accounts, sessions,
regenerating Turns, and transactional game actions. Relay demonstrates a
downstream game with cooperative shared progress.

## Capabilities and Constraints

Games own their rules, data, and presentation. Relay's interface is a minimal,
readable developer demonstration. Player actions must work without JavaScript,
share the authenticated action pipeline with the JSON API, and preserve
request-ID retry semantics.

## Accessibility & Inclusion

Use semantic HTML, associated labels, keyboard-operable controls, visible
focus, responsive layout, and status messages that do not rely on color alone.
